# Datasets Documentation

This directory provides guidelines and documentation regarding data sourcing, annotation schemas, and synthetic generation for JewelMind:

- **Source Integrity:** All dataset sources, licensing, and attribution will be recorded here.
- **Annotation Standards:** YOLO bounding box format (`class_id x_center y_center width height`) and label hierarchies.
- **Synthetic Data Protocols:** Clear documentation of synthetic generation formulas for manufacturing data (hours, costs, scrap rate) to ensure transparent academic evaluation.
- **Storage Rules:** Raw and processed dataset files remain in the `datasets/` root folder and are excluded from Git version control.
