# AI Subsystem Documentation

This directory will store detailed AI/ML methodology notes, model benchmarking results, hyperparameters, and evaluation metrics:

- **Computer Vision (YOLO):** Annotation guidelines, class definitions (stones, clasps, hooks, beads), mAP@0.5 and mAP@0.5:0.95 evaluation scores.
- **Generative Rendering:** Diffusion pipelines, ControlNet conditioning modes (Canny, LineArt, Depth), prompt engineering, and LoRA checkpoints.
- **Predictive Regression (XGBoost):** Feature selection, hyperparameter tuning, cross-validation metrics ($R^2$, MAE, RMSE) for material weight, cost, production hours, and wastage.
- **Constraint Optimization (OR-Tools):** Mathematical formulation of workshop scheduling, decision variables, hard/soft constraints, and objective functions.
