# Project-Wide Test Suites

This directory contains cross-cutting integration and end-to-end (E2E) automated tests for JewelMind.

---

## Directory Structure
- `integration/`: Tests verifying the API-to-Worker communication and database transaction pipelines.
- `e2e/`: Full workflow tests (Sketch upload $\rightarrow$ AI Job dispatch $\rightarrow$ Result visualization $\rightarrow$ Schedule optimization).
