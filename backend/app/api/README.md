# API Routers Directory

This directory will contain modular route handlers:
- `auth.py`: Authentication, registration, login endpoints (Phase 2).
- `designs.py`: Jewellery design CRUD endpoints (Phase 3).
- `sketches.py`: Sketch upload & preview endpoints (Phase 4).
- `ai.py`: AI job dispatch and status polling endpoints (Phase 5).
- `predictions.py`: ML prediction endpoints for material, cost, time, wastage (Phase 9).
- `production.py`: Production order management endpoints (Phase 11).
- `optimization.py`: OR-Tools schedule generation endpoints (Phase 12).
