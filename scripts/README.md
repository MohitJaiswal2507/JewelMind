# Scripts & Automation Utilities

This directory contains standalone execution scripts, dataset downloaders, benchmark utilities, and environment verification tools:

- `setup_environment.py`: Automated environment and CUDA checker (planned).
- `download_sample_data.py`: Script to download public jewellery dataset samples (planned).
- `generate_synthetic_manufacturing_data.py`: Generator for tabular cost, time, and wastage simulation datasets (planned).
- `run_local_worker.py`: Launch script for the local RTX 4060 AI worker (planned).
