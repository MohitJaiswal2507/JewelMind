# JewelMind Vision Models Directory

This directory contains model metadata, architecture notes, and local checkpoint tracking.

> [!CAUTION]
> **Strict Git Policy:** Model weight binaries (`*.pt`, `*.pth`, `*.onnx`, `*.safetensors`, `*.bin`, `*.engine`) MUST NEVER be committed to Git.
> All `.gitignore` rules actively exclude these files.
> Training outputs and checkpoints are written to `runs/jewellery/` and are also gitignored.

Refer to [YOLO_COMPONENT_MODEL.md](../../../docs/ai/models/YOLO_COMPONENT_MODEL.md) for metadata and version tracking.
